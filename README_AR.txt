MX YouTube Clean - Chrome Extension v1.0
========================================
إضافة خاصة لمتصفح Chrome على Windows / macOS / Linux.
تفتح موقع يوتيوب الحقيقي وتحاول تقليل الإعلانات بثلاث طبقات:
1- حظر طلبات شبكات الإعلان من YouTube.
2- حذف بيانات مواضع الإعلان من مشغل الصفحة عند البداية.
3- إخفاء البانرات وتخطي الإعلانات بالفيديو إذا تعرف عليها المشغل.

طريقة التنصيب (على الكمبيوتر):
1. فك ضغط ملف MX_YouTube_Clean.zip بمجلد ثابت. لا تحذف هذا المجلد بعد التنصيب.
2. افتح كروم واكتب chrome://extensions
3. شغّل Developer mode.
4. اضغط Load unpacked واختار المجلد MX_YouTube_Clean الذي يحتوي manifest.json.
5. راح تنفتح صفحة MX YouTube تلقائياً. اضغط افتح يوتيوب.
6. ثبّت أيقونة الإضافة من قائمة Extensions حتى ترجع للصفحة بسرعة.

ملاحظة مهمة: مو كل إعلانات فيديوهات يوتيوب قابلة للحجب دائماً.
يوتيوب يبدّل طرق البث والإعلانات بشكل مستمر.
الإضافة مو مضمونة 100%، وما تفحص فيديوهاتك ولا بيانات حسابك.
لا تشتغل على Chrome آيفون؛ كروم iOS ما يدعم إضافات سطح المكتب.

ماكو مزودات بديلة: الفيديوهات تبقى على YouTube نفسه.
هذه نسخة محلية ما ترفع بيانات لأي سيرفر ولا تحتاج حساب.
