# MX YouTube Clean

Chrome Manifest V3 extension to open the official YouTube website with ad-request filters, player ad skipping attempts and a dark MX start page.

## Install

1. Download or clone this repository.
2. Open `chrome://extensions` in desktop Chrome.
3. Enable **Developer mode** and click **Load unpacked**.
4. Select the repository root.

This extension does not guarantee ad-free playback on every version of YouTube. It is not compatible with Chrome extensions on iOS.
