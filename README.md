# MX YouTube Clean

Chrome Manifest V3 extension that opens the official YouTube website with ad-request filters, player ad skipping attempts and a dark MX start page.

## Install

1. Download or clone this repository.
2. Open `chrome://extensions` in desktop Chrome.
3. Enable **Developer mode** and click **Load unpacked**.
4. Select the repository root (the folder with `manifest.json`).

YouTube can change its ad delivery at any time, so ad blocking is not guaranteed for every video. Chrome on iPhone does not support desktop extensions.
